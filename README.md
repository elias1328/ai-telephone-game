# 🎮 AI Telephone Game

An experiment that chains AI agents in a [telephone game](https://en.wikipedia.org/wiki/Chinese_whispers) (whisper game) to observe how text degrades as it passes through successive AI "players."

Give the first agent a paragraph of text, and watch as each agent tries to repeat it — with increasingly fascinating mutations, hallucinations, and drift.

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## 🎯 How It Works

```
┌────────────┐    ┌─────────┐    ┌─────────┐         ┌─────────┐
│ Start Text │───▶│ Agent 1 │───▶│ Agent 2 │──▶ ... ─▶│ Agent N │
└────────────┘    └─────────┘    └─────────┘         └─────────┘
```

1. A starting paragraph is provided (or generated by the AI)
2. Agent 1 receives the text and tries to repeat/recall it
3. Agent 2 receives Agent 1's output (not the original!)
4. This continues through N agents
5. The final output is compared against the original

Like the classic children's game — but with language models. The text inevitably drifts, and the *way* it drifts reveals fascinating things about how LLMs process and reconstruct language.

## ✨ Features

- **Dual providers**: Use local [Ollama](https://ollama.com/) models or the [Google Gemini API](https://ai.google.dev/)
- **Web UI**: Clean dark-themed browser interface with live-streaming results
- **CLI mode**: Full-featured command-line interface
- **Toggleable difficulty modes**:

| Mode | Description | Effect |
|---|---|---|
| 🧠 **Recall** | "Remember from memory" prompt | Forces paraphrasing instead of copying |
| 📝 **Summarize + Expand** | Odd agents summarize, even agents expand | Guarantees information loss each cycle |
| ██ **Redact** | Randomly masks ~20% of words with `[???]` | Agents must fill in blanks (often wrong) |
| 🌀 **Distraction** | Surrounds text with unrelated paragraphs | Buries the signal in noise |
| 🌡️ **Temperature** | Adjustable creativity/randomness | Higher = more chaotic output |

- **Auto-generate starting text**: Let the AI create the starting paragraph on a topic of your choice
- **Mix and match**: Difficulty modes stack — enable multiple for maximum chaos

## 📦 Installation

### Prerequisites

- Python 3.10+
- [Ollama](https://ollama.com/) installed and running (for local models), **and/or**
- A [Gemini API key](https://ai.google.dev/) (for cloud models)

### Setup

```bash
git clone https://github.com/elias1328/ai-telephone-game.git
cd ai-telephone-game
pip install -r requirements.txt
```

### Ollama Setup

Make sure Ollama is running and you have at least one model:

```bash
ollama serve                    # start the Ollama server
ollama pull llama3.2            # download a model
```

### Gemini Setup (optional)

```bash
export GEMINI_API_KEY='your-api-key-here'
```

## 🖥️ Web UI

```bash
python3 whisper_game_web.py
```

This opens a browser at `http://127.0.0.1:5000` with:

- **Sidebar** with all settings: provider toggle, model selector (auto-populated from Ollama), agent count slider, temperature slider, difficulty mode toggles
- **Results area** with live-streaming cards that slide in as each agent responds
- **Summary table** with word count progression
- **Stop button** to abort mid-game

Options:
```bash
python3 whisper_game_web.py --port 8080      # custom port
python3 whisper_game_web.py --no-browser     # don't auto-open browser
```

## ⌨️ CLI Usage

```bash
# Default: Ollama, 5 agents, recall mode
python3 whisper_game.py

# Use Gemini API
python3 whisper_game.py --provider gemini

# 10 agents with generated starting text
python3 whisper_game.py --num-agents 10 --generate-start-text --start-text-topic "the invention of the printing press"

# Summarize + Expand mode with word count limit (match original length)
python3 whisper_game.py --mode-summarize-expand --expand-word-limit original

# Summarize + Expand with custom word limit (e.g. 60 words)
python3 whisper_game.py --mode-summarize-expand --expand-word-limit 60

# Export results to Markdown or JSON
python3 whisper_game.py --num-agents 5 --export results.md
python3 whisper_game.py --num-agents 5 --export results.json

# Hard mode: redaction + distraction + high temperature
python3 whisper_game.py --mode-redact --mode-distraction --temperature 1.5

# Custom starting text
python3 whisper_game.py --start-text "The quick brown fox jumped over the lazy dog."

# Verbatim mode (no difficulty — how well can it copy?)
python3 whisper_game.py --no-mode-recall

# Use a specific Ollama model
python3 whisper_game.py --ollama-model qwen3.5:2b --num-agents 8

# See all options
python3 whisper_game.py --help
```

## 🔬 What to Watch For

Running this experiment reveals several interesting patterns in how LLMs process text:

- **Semantic drift** — meaning shifts subtly each round
- **Quote "correction"** — models "fix" quotes to what they think is correct (e.g., adding the missing "a" in Armstrong's quote)
- **Vocabulary homogenization** — text converges toward generic "AI style"
- **Detail hallucination** — agents fill in gaps with plausible but invented details
- **Abbreviation creep** — "United States" → "US", "television" → "TV"
- **Formality shifts** — "broadcast to" → "shown on"
